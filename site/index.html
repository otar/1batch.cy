    Upload in 1bank

    After “Download XML”, do these six steps. You need your Digipass two times.

    1. 1Open Multiple Payments

      Log in to 1bank. Go to Transfers & Payments › Mass Payments › Multiple Payments.

      (opens a larger image in a new tab)

    2. 2Upload the file

      Click Select file and select the XML file. Then click Upload.

      (opens a larger image in a new tab)

    3. 3Compare the totals

      Make sure that 1bank shows the same number of payments and the same total as this page.

      (opens a larger image in a new tab)

    4. 4Confirm the upload

      Enter the Digipass code. Then click Confirm.

      (opens a larger image in a new tab)

    5. 5Read the result

      Read the result in 1bank Messages. Now 1bank makes a pending payment for each payment in the file. If 1bank rejects a payment, make a new file with only that payment.

      (opens a larger image in a new tab)

    6. 6Confirm the pending payments

      Go to [Pending Payments]. Confirm the payments with a second Digipass code. Then the bank sends them.

      (opens a larger image in a new tab)

    FAQ

    18 questions

    Who can use this page?

    Bank of Cyprus business customers who use 1bank with Multiple Payments. The debit account must be a Bank of Cyprus account in euro. If you do not see Multiple Payments in 1bank, ask your relationship manager.

    Is it free? Who made it?

    Yes, it is free and open source (MIT licence). Otar Chekurishvili, an independent developer, made it. It is not made by, or connected to, Bank of Cyprus. The code is on GitHub.

    Can I stop and continue later?

    The page keeps nothing. Before you close the tab, download the XML file. If there are problems, use Export CSV. Next time, open the file here.

    Can I use it on a phone?

    Yes. On a phone, each payment shows as a card. For a large batch, a computer is faster: you can paste from Excel and use the keyboard.

    Can I use it with a screen reader or with only a keyboard?

    Yes. The target is WCAG 2.2, level AA. All functions work with the keyboard, and Ctrl+Z (⌘Z on a Mac) also does Undo. Automatic tests examine the keyboard, the focus, the contrast and the labels. Tests with screen readers are not complete yet. One exception: autocomplete is off for privacy, so your browser does not fill in the company name. If something does not work for you, report it on GitHub.

    Is there a command-line tool?

    Yes: boc_payments_xml on GitHub. It uses the same rules and makes the same XML. It reads CSV files in the same format as Export CSV.

    Where does my data go?

    Nowhere. The page runs only in your browser. Its security policy blocks all connections to servers. It uses no cookies and no storage, so the data is gone when you close the tab. There are no analytics, ads, fonts or scripts from other sites.

    How can I check this?

    Open the page, then turn off Wi-Fi or remove the network cable. Make a file and download it. It works, because the page does not use the network. You can also read the three code files with View Source.

    SEPA or TBOC: which one?

    TBOC is a transfer to a Bank of Cyprus account. SEPA is a euro transfer to a bank in the SEPA zone. The page sets the type from the IBAN. To change it, use the “Type, BIC and more” button (⋯) on the row.

    Which characters can I use?

    A–Z, a–z, 0–9, space and / - ? : ( ) . , ' + The bank does not accept accents, Greek letters or &. Names: 35 characters maximum. Descriptions: 140. For many errors, the page shows a button with a correction.

    Which execution date can I use?

    Today or a later business day. If you open an old file with a past date, the page moves it to the next business day. The bank has cut-off times for each payment type. For the times, see the Bank of Cyprus website or ask your relationship manager.

    How many payments can one file have?

    The page has no limit. 1bank can have a limit for each file: ask your relationship manager. With 1000 or more payments, the file reference must be shorter. The page tells you.

    What does the page check?

    The same rules as the command-line tool: names, IBANs, BICs, amounts, descriptions and the date. If one check fails, the page does not make the file. The bank name comes from a short list in the page. It does not prove that the account exists.

    Which CSV format can I open?

    The format of the command-line tool. The first line is type,name,iban,bic,amount,description. Then one line for each payment. Use Export CSV to get a correct example. A CSV file has no “Pay from” data.

    1bank does not accept the file. What now?

    Read the message in 1bank. Make the correction here, then download a new file and upload it. If the message is not clear, ask your relationship manager.

    1bank rejected one payment. What now?

    Make a new file with only that payment. Do not upload the full file again: the other payments would go two times.

    What are the bank fees?

    The page does not add fees. For the bank fees, see the Bank of Cyprus price list or ask your relationship manager. In the file, SEPA payments use shared charges (SLEV).

    How do I use an old XML file again?

    Click “Open XML or CSV” and select the old XML file. The page fills in all the fields and offers to change the month in the descriptions. Change the amounts, then download a new file.
